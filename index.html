GitHub 올리기 & 소스 코드 내보내기 Guide

STEP 1 깃허브(GitHub)에 내 게임 무료로 무료 웹호스팅하기

  1. GitHub 접속 후 로그인합니다 (없으면 계정 생성).
  2. 우측 상단 + 버튼 클릭 → New repository 선택.
  3. Repository name에 예: acid-rain-typing 입력 후 Create repository 클릭.
  4. 아래 버튼을 눌러 소스 코드를 index.html 파일로 저장합니다.
  5. GitHub 저장소 화면에서 uploading an existing file 링크를 눌러 저장한 index.html 파일을 올리고 Commit changes 합니다.
  6. 저장소 메뉴 중 Settings → 좌측 Pages 메뉴 이동.
  7. Branch를 main (또는 master)으로 선택 후 Save를 누르면 몇 분 후 나만의 게임 URL이 생성됩니다! 🎉
